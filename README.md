# Healthcare – Early Readmission Risk Prediction

## Project Overview

This project focuses on predicting early hospital readmission risk using machine learning techniques and the Diabetes 130-US Hospitals dataset (1999–2008).

The main objective is to identify patients at risk of being readmitted within 30 days of discharge.

## Project Objectives

- Understand and explore healthcare data.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Apply feature engineering techniques.
- Develop and compare machine learning classification models.
- Evaluate model performance.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Machine Learning

## Dataset

The project uses the Diabetes 130-US Hospitals dataset.

Dataset files:
- `diabetic_data.csv`
- `IDS_mapping.csv`

## Machine Learning Models

Multiple classification models were evaluated, including:

- Logistic Regression
- Decision Tree
- Random Forest
- Extra Trees

The Extra Trees model was selected based on cross-validation performance.

## Project Results

- Test PR-AUC: 0.2300
- Test Recall: 0.4581
